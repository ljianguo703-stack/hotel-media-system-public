从解压到安装完成

  1. 解压完整便携包，双击本系统启动程序。无需安装 Python、Java、Node 或 Android Studio；保留终端窗口，浏览器是操作窗口。
  2. 电视与电脑进入同一局域网，在电视开启调试；输入 IP 检测，在电视选择“始终允许”。无线调试先使用电视显示的配对 IP、端口和6位码配对，再填写连接端口。
  3. 接入服务器：勾选“现在接入服务器”，填服务器 IP 和后台管理员账号密码，点“登录后台”。之后每台电视安装时，工具自动在后台“客房设备”登记（房间名可填，留空为“待命名-IP尾号”）、把它的凭证通过调试写入电视，并等后台看到电视上线来确认连接；不用再复制凭证。密码只用于登录，不保存。已经接在这台后台的电视保留原连接。也可不勾选先装电视，之后在电视员工维护页填写。
  4. 首次给本店生成统一员工 PIN，立即保存。后续安装复用工具 data/hotel.json 中的哈希。当前已安装电视不会因点击生成而自动换 PIN。
  5. 检测后看安装级别：本项目实测的固件和网上已证（Aerial 同源守护实测、型号代码精确）的型号可直接一键安装；其他型号显示“允许试装”，勾选后才安装；网上已知失败的型号标“不建议”，需再次确认。每台电视都会先预检重启（确认失败时能自动还原），非本项目实测的型号装完再做 2 分钟稳定观察。新型号建议先点“只读体检”保存报告。点击“一键安装”后，工具备份原状态、安装对应 standard/guard 客户端，读回已装 APK，授予并确认守护真实绑定，两轮 HOME 稳定返回检查，写入员工PIN，再软件重启电视验证开机接管；全部通过后才关闭调试，任何一步失败都会当场自动还原。
  6. 看到“重启验证（软件重启）已通过”，再到电视前验遥控/HOME、员工PIN、拔电开机和遥控待机唤醒（软件重启不能代替这两项）。没在安装时接入服务器的，以后可在电视按MENU→员工PIN→填写局域网片库地址/客房设备凭证→保存并连接（或再点一次一键安装并登录后台），再验本店画面、影片、频道和广告。
  7. 需要恢复时重新开启电视调试，在“恢复与报告”选择对应备份；首次安装的电视会被还原到安装前（原厂桌面、卸载影院），默认再重启复查一次。这台电脑没有备份时可“从电视读取还原点”。保存完整 data 目录；它含本店 PIN 哈希、TV 信息、恢复 APK与日志，应作为本店私有资料保管。

各品牌如何开启调试

小米/Redmi：设置→关于，连续按产品型号，随后账号与安全→ADB调试/未知来源安装。TCL/雷鸟：设置→关于→本机信息，部分固件快速按上、下、左、右后出现更多。OPPO：关于本机→设备型号，部分固件按上、上、右、右、确认，再进入开发者选项。原生Android/Google TV、索尼等：关于→内部版本号连续按7次→开发者选项→USB/网络调试。路径随固件变化；没有合法调试授权入口的型号暂不支持。

故障处理

  • 连接超时：核对电视 IP、访客网络隔离、防火墙和调试开关。配对码不是员工 PIN，投屏码也不是配对码。
  • 签名不匹配：工具停止，不会卸载强装。找回原签名更新包；原签名私钥不会装入便携包。
  • HOME 没回影院、被厂商桌面抢回、或重启后没进影院：自动还原原 HOME（首次安装的电视卸载影院），保留备份及报告；该固件记为失败，暂不支持。
  • 重启后连不上调试：工具不会宣称成功，也不会关闭调试；到电视前确认开机画面，异常时重新打开调试后用备份还原。
  • 尚未接入服务器时没有片库属于待配置状态；以后在员工维护页接入，再检查设备启用和作品上架。安装工具不修改片库、广告或后台账号。
  • 完成后无法连接：重启验证通过后工具才请求关闭 ADB，电视端员工维护菜单可进入系统设置重新打开；工具不会常驻保持电视调试开启。
  • Tizen/webOS/VIDAA/Roku 等：现有 Android APK 无法直接运行；本版列出研究来源，不给电视换成参考项目的另一套界面。

复制、依赖与升级

便携包已包含对应系统的 ADB、两种客户端、机型库和离线说明。给另一台电脑复制时用全新压缩包；不要分发本店 data、签名私钥或生产设备凭证。更新时关闭工具，解压新版整包，将本店 data 单独备份后转移；不用替换远程脚本。Windows x64、Mac Apple Silicon/Intel、Linux x64 各用对应包。Mac首次可能需在系统安全设置允许打开；Linux需系统自带浏览器、glibc与常见系统库。详细依赖、来源、限制和校验见随包说明。
