# 电视／盒子连接开启方式与机型索引

核对日期2026-11-03。设备连接、APK安装、HOME接管、开机／待机、AC来电亮屏分别验收。

包含26类连接方法、216条本工具机型记录及420条上游目录链接。记录数不是本影院已验型号数。

手机模式：先在Ubuntu启动“启动手机局域网安装.sh”，手机打开终端网址并输入8位手机连接码。以下步骤在目标电视／盒子上操作；6位ADB配对码不是手机连接码或员工PIN。

## 按品牌和设备类型连接

### 小米／Redmi 电视

**状态：参考方法；须按型号/固件现场核对**

1. 设置 → 关于，连续按产品型号／产品类型进入开发者模式。
2. 设置 → 账号与安全，开启ADB调试及允许未知来源安装。
3. 网络设置查看IP，在工具检测；电视出现授权框时选“始终允许”。

- 待机或开机后部分固件会关闭ADB；沿用已验安装器的调试保持和重连流程。
- 通电亮屏是独立原厂能力，仅本店MiTV-ASTP0精确固件已有PW01证据。

方法依据：[来源](https://github.com/pengchujin/aerial-tv/blob/bf64c3090c0ae71912f0a9753dd1d453d4705f06/docs/devices/adb-by-brand.md)

### TCL／雷鸟 国行电视

**状态：参考方法；须按型号/固件现场核对**

1. 设置 → 关于 → 本机信息，快速依次按“上、下、左、右”。
2. 若底部出现“更多”，进入并开启ADB；在网络设置查看IP。
3. Android11+只有无线调试时先查看是否存在配对码入口；有入口才用工具无线配对。

- 部分MT9655／Q10M等只有动态端口且无配对入口，需要设备支持的数据线先授权；手机网页不能代替这一步。
- 有线方法按具体机型笔记，不能把任意USB A对A线当作通用连接方法。

方法依据：[来源](https://github.com/pengchujin/aerial-tv/blob/bf64c3090c0ae71912f0a9753dd1d453d4705f06/docs/devices/tcl-mt9655-cn.md)

### OPPO ColorOS TV

**状态：参考方法；须按型号/固件现场核对**

1. 设置 → 系统 → 关于本机 → 设备型号，部分固件依次按“上、上、右、右、确认”。
2. 根据提示完成后返回系统 → 开发者选项，开启USB／ADB调试。
3. 网络 → 已连接网络，页面最下面查看IP。

- 部分固件只允许特定包名当HOME；能连上和能安装不代表本影院已可接管。

方法依据：[来源](https://github.com/pengchujin/aerial-tv/blob/bf64c3090c0ae71912f0a9753dd1d453d4705f06/docs/devices/oppo-coloros-tv.md)

### 海尔／模卡 MOOKA

**状态：参考方法；须按型号/固件现场核对**

1. 按电视机身信号源键打开菜单，再用遥控器依次按“左、左、上、右”。
2. 若出现海尔工厂菜单，仅打开ADB调试；部分机型位于第二页Other Option。
3. 退出菜单，查看网络IP，再用工具检测并在电视授权。

- 这是部分固件的社区记录；不要更改工厂复位、屏参或其他工程选项。

方法依据：[来源](https://github.com/pengchujin/aerial-tv/blob/bf64c3090c0ae71912f0a9753dd1d453d4705f06/docs/devices/adb-by-brand.md)

### 索尼 BRAVIA

**状态：参考方法；须按型号/固件现场核对**

1. 设置 → 系统／设备偏好设置 → 关于，选“内部版本号／Build”，连续按确认7次。
2. 返回开发者选项，打开USB调试／网络调试；若只有无线调试，使用“配对码配对设备”。
3. 在网络设置查看目标设备IP；有网络调试时用设备显示的端口，只有明确旧式网络ADB时才默认5555。
4. 在目标设备确认信任Ubuntu／电脑，选“始终允许”；只有配对码时，工具里分别填写配对端口、6位码和连接端口。

- 入口因系统地区和固件不同；只有实际提供的开关才可使用。
- 名字含VIDAA的Android固件与真正VIDAA OS不同；先检测SDK和运行时。

方法依据：[来源](https://developer.android.com/tools/adb)

## 换Mac或其他施工电脑时

每台电脑须分别得到电视确认；复制工具包或本店PIN文件不等于取得ADB信任。优先双击完整包中的.command脚本从Terminal启动，保留终端窗口，再用工具检测。没有电视弹窗时点“重新请求电视授权”，仅重连当前填写的目标。

如果实际ADB返回Connection refused，先查电视调试开关和连接端口；No route to host等错误先查IP、网络隔离或对应启动程序的局域网访问权限。这些都不能直接当成电视未授权。使用6位配对码的无线调试，仍须先配对，再填连接端口。

不复制旧电脑ADB私钥、不删除现有密钥、不全局kill-server，不修改系统范围的隐私豁免设置。Apple对Terminal/SSH命令行与其他启动方式的说明：[TN3179](https://developer.apple.com/documentation/technotes/tn3179-understanding-local-network-privacy)。ADB连接命令返回机制见[AOSP commandline.cpp](https://android.googlesource.com/platform/packages/modules/adb/+/refs/heads/main/client/commandline.cpp)。
